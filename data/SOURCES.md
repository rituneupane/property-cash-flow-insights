# Sources

72-month property cash-flow model. Tenants anonymized A–D.

| File | What it is |
|---|---|
| `annual_summary.csv` | 2026–2030 NOI, DSCR, debt yield, cash-on-cash |
| `assumptions.csv` | Value, debt, inflation, vacancy, exit cap |
| `tenant_rent_roll.csv` | Lease windows |
| `partnership_waterfall.csv` | 80/20 JV, 8% pref, 50/50 promote |
| `metrics.json` | Headline results |

Inputs from the source pro forma: 3% inflation, 12% vacancy, 3% management fee, 8.5% exit cap, 9.5% discount rate, 70% LTV, 5.5% loan. Building size is 145,000 SF from Year-1 reimbursable expense of $2,030,000 at $14/SF.
